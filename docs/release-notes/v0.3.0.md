# Parcels 0.3.0

A new look, Postal.

- Pickup codes and PINs are printed on stamps: a large one for a box code, a small one for a counter PIN.
- A parcel you mark as collected gets a postmark, and an airmail stripe marks a parcel that is out for delivery. A failed delivery is stamped with the carrier's own words.
- Cream paper, a serif for headings and a typewriter face for codes. Dark mode is a warm brown, not black.
- A little motion, which stays off if your Mac is set to reduce motion.
- A new app icon and menu-bar icon.

Prefer the old look? In Settings, under Appearance, choose Classic. You can also pin light or dark mode there.
