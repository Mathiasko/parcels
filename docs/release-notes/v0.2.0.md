# Parcels 0.2.0

A new look, Postal. Pickup codes are printed on stamps, collected parcels get a postmark, and an airmail stripe marks a parcel that is out for delivery. It comes with a new app icon and menu-bar icon. Prefer the old look? Choose Classic under Appearance in Settings, where you can also pin light or dark mode.

Set up before 0.2.0? Import the filter again and delete the old one, so Czech mail is labelled too.
Gmail never updates a filter it has already imported. In Settings, download the new filter, import it in Gmail, delete the old one, then press "Done, I imported it again".

- Pickup PINs are shown for every carrier, not just some.
- Quieter notifications, with three switches in Settings: progress updates (off by default), the daily reminder to collect a parcel, and delivered.
- Simpler wording in the Gmail setup steps.
- Czech mail: Zásilkovna mail is now in the filter, and PPL parcels are tracked. PPL has not yet been checked against a real parcel.
