# Parcels 0.3.1

A new header, and an empty dashboard that only gives the all-clear when it has earned it.

- A navy header across the top of every page, with Refresh and Add parcel together in it.
- With nothing in flight, the dashboard says "Nothing to collect", stamped with the time of the last check.
- It says that only when it is true. If Gmail could not be read, the checks have stopped or an email is waiting on you, it says so instead.
- Every parcel in flight now has Mark as collected or Mark as received on the dashboard, not only those waiting at a pickup point.
- The Health warning dot now stays beside its word.

The header and the stamp are part of the Postal look. Classic stays as it was.
